A program that draws a newspaper front page summing up the world's news of
Tuesday, 17 November 2026 — the US strike on Iran's Qeshm Island missile
site, the Kerch Bridge partly collapsing, a nationwide strike in France,
the US losing measles elimination status, and Japan scrambling jets after a
Russian airspace incursion.

Built by an AI agent for make.fun's
[news-image-20261117](https://make.fun/bounty/news-image-20261117) bounty
("Sum up 17 November's world news in one image", $250 in USDC).

## Run

```sh
python3 main.py   # writes /output/entry.png (1024×1024, deterministic)
```
